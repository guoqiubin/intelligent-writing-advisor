# 托德学院创作工作台

一个面向内容创作者的内容生产工作平台。它把读书会写作、书籍拆解、声画同步和封面生成放在同一个入口下，帮助用户从素材与想法出发，逐步完成可审核、可导出的内容作品。

## 在线体验

- 产品入口：<https://intelligent-writing-advisor.vercel.app>
- 当前线上版本：`v2.1.28`
- 使用说明：见 [`docs/wiki/首页.md`](docs/wiki/首页.md)

> 说明：读书会写作、书籍拆解和封面生成可在线体验；声画同步的视频渲染依赖用户电脑上的本地 Chrome、FFmpeg/ffprobe 与本地渲染服务，属于本地创作模块。

## 适合谁

- 需要稳定生产课程稿、读书会稿件或知识解读文稿的内容团队。
- 需要在 AI 生成过程中保留人工确认、反馈和审核环节的创作者。
- 需要把音频、PDF 页面和文稿标记整合成 MP4 的单人创作者。

## 主要模块

| 模块 | 作用 | 当前状态 |
| --- | --- | --- |
| 读书会写作 | 从学员困惑出发，完成选书、资料准备、结构设计、写作与审核 | 可用 |
| 书籍拆解 | 上传一本书，完成知识解读、写作设置、文稿生成与审核 | 可用 |
| 声画同步 | 将 MP3、带分页标记的 DOCX 和 PDF 页面合成为 MP4 | 本地创作模式 |
| 封面生成 | 通过尺寸、书籍封面、文案和参考图生成海报 | 可用 |

## 从哪里开始

1. 第一次使用，先阅读 [`docs/wiki/首页.md`](docs/wiki/首页.md) 和 [`docs/wiki/使用指南.md`](docs/wiki/使用指南.md)。
2. 想生成文章，进入“读书会写作”或“书籍拆解”。
3. 想生成视频，先准备 MP3、标记口播稿 DOCX 和 PDF 页面，再阅读声画同步说明。
4. 想做书籍海报，进入“封面生成”，严格检查主文案和副文案后再提交。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/` 即可查看写作与封面模块。

声画同步需要额外启动本地渲染服务：

```bash
npm run dev:sync
```

然后打开 `http://127.0.0.1:4175/`。完整的使用前提、素材格式和验收方式见 [`docs/wiki/使用指南.md`](docs/wiki/使用指南.md)。

## 项目结构

```text
src/main.jsx                 主应用入口与业务导航
src/workflow.js              工作流状态、版本记录与本地存储
src/styles.css               统一视觉规范与响应式样式
src/sync-studio/             声画同步上传、解析、预览和渲染交互
src/sync-render/             Remotion 视频合成组件
src/cover-generator/         封面生成工作台
api/                         在线 AI 与文件接口
docs/wiki/                   面向非开发者的产品说明
```

## 内容与版本

- 新增功能先更新产品模块说明，再更新使用指南。
- 每次迭代记录在 [`CHANGELOG.md`](CHANGELOG.md)。
- 业务流程的稳定 ID 不随文案调整而改变。
- 本地视频、日志、API 密钥、私有头像和个人测试素材不进入公开仓库。

## 安全与隐私

公开仓库不包含 `.env`、API Key、Token、Cookie、个人用户记录、渲染输出、运行日志或本地部署配置。真实 AI 调用必须通过本地环境变量配置密钥，任何密钥都不应写入前端代码或提交历史。

## 许可证与第三方资源

本仓库用于作品集展示和产品原型交流。使用前请确认字体、头像、书籍封面、音频、PDF 和其他第三方素材的授权范围；示例素材不代表可以直接用于商业发布。
