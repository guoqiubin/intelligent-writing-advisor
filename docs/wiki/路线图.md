# 路线图

## 已完成

- 读书会写作与书籍拆解的阶段化内容生产流程。
- 声画同步的本地 MP4 工作台、验收视频、字幕开关和渲染历史。
- PDF 页面高清渲染、固定码率和页面切换黑帧修复。
- 封面生成的比例选择、书籍封面、参考图、文案合成和风格保存。

## 近期计划

- 继续提升 PDF 到视频的清晰度、编码稳定性和大文件处理能力。
- 完善 Whisper/WhisperX 字幕时间对齐实验，但与当前 MP4 导出流程解耦。
- 增强素材评估提示，让用户在正式渲染前更早发现页数、标记和文件问题。

## 远期探索

- 支持 PPT/PPTX 原文件的高清页面提取。
- 研究 WPS/PPT 动画与单元素时间控制。
- 将更多内容创作工具接入统一工作台。
