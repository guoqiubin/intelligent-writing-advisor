# 使用指南

## 1. 读书会写作

1. 输入或生成学员困惑。
2. 确认后进入书籍匹配。
3. 选择资料准备模式。
4. 提取并确认书籍观点。
5. 确认结构框架。
6. 设置写作方式、字数和参考稿。
7. 生成文稿并进行 AI 审核。

如果已经有完整内容大纲，可以在第一步使用“已有内容大纲”入口，直接进入写作设置。

## 2. 书籍拆解

上传中文书籍后，依次进行知识解读、写作设置、文稿生成和审核。当前纯英文书籍不进入解读流程；中文书籍中出现英文段落或术语不属于这个限制范围。

## 3. 声画同步

准备三份素材：

- MP3：正式口播音频。
- DOCX：口播稿，并使用稳定的分页标记，例如 `[第 1 张 PPT]`、`PPT 29 -` 或 `[第29页]`。
- PDF：与音频对应的页面素材。

上传后先看页面数量和分页识别结果，再生成 1 分钟验收视频，检查画面比例、清晰度、翻页和字幕。确认无误后，再生成完整 MP4。

“本轮生成字幕”只控制字幕是否嵌入 MP4，不再输出 SRT 文件。

声画同步是本地创作模块，需要本机的 Chrome、FFmpeg/ffprobe 和 Remotion 服务；渲染速度取决于本机配置。

## 4. 封面生成

- 书籍封面：作为画面中的真实书籍封面插入，内容本身不修改。
- 参考图：用于学习标题、副标题、书封位置和整体版式。
- 主文案和副文案：必须逐字准确，生成后仍应人工检查。
- 生成结果：可以下载到本地、再次生成或保存风格。

## 遇到问题怎么办

先查看页面上的具体提示，再检查文件格式、文件名、页数、分页标记和本地服务是否启动。不要把 API Key、真实用户资料或原始渲染日志直接发到公开仓库。
